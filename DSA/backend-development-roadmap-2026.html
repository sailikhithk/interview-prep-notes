@sailikhithk Phase 01 · Core Java
01

Core Java Fundamentals

Weeks 1–2 · The non-negotiable foundation

Before touching any framework, be comfortable with Java as a language. Most beginners rush past this phase and then struggle with Spring Boot. Spend two full weeks here and you'll save yourself weeks of confusion later. Focus on understanding how things work, not just on making them work.

WEEK 1 Java Basics & Control Flow
✍️

Daily practice: spend the first 30 minutes of each session writing code, not watching videos. After every concept, write 2–3 small programs from scratch without looking. The goal is muscle memory — you should write a basic loop or method without thinking.

Topics to Cover
  • Setting up JDK 21 + IntelliJ IDEA (Community Edition is free)
  • Data types, variables, type casting — int, long, double, String, boolean
  • Operators: arithmetic, relational, logical, bitwise
  • Control flow: if/else, switch expressions (Java 14+ style), ternary
  • Loops: for, while, do-while, enhanced for-each
  • Arrays: single-dimensional and 2D, iterating, common operations
  • Methods: defining, calling, return types, method overloading
  • Scanner for user input — write small interactive programs
Resources
  • PRIMARYMOOC.fi Java Programming — free, project-based, excellent exercises
  • REFERENCEOracle Java Docs (docs.oracle.com/javase/tutorial)
  • PRACTICEHackerRank Java domain — complete all Easy problems in Week 1
  • VIDEOTelusko YouTube — Java Tutorial for Beginners (selective watching)
🎯Milestone

Build a basic calculator, a number guessing game, and a simple grade calculator — all from scratch, without copying.

02

Java Deep Dive & Modern Features

Week 3 · Write Java the way professionals write it

This week bridges the gap between beginner Java and production Java. You'll learn the features that make Java code clean, concise and industry-standard. Many tutorials skip these — don't. Interviewers and code reviews will expose gaps here.

WEEK 3 Generics, Functional Java & Modern APIs
💡

Why this matters for Spring Boot: Spring Boot 3+ requires Java 17. Streams are used everywhere in service layers; lambdas appear in filter chains, comparators and event handlers. Without these, Spring Boot code feels like magic and you can't debug it.

Topics to Cover
  • Generics — generic classes & methods, bounded type parameters, wildcards
  • Java 8: Lambda expressions, functional interfaces (Predicate, Function, Consumer, Supplier)
  • Stream API — filter, map, reduce, collect, sorted, distinct, limit
  • Optional — avoiding NullPointerException the right way
  • Java Records (16+) — immutable data carriers
  • Sealed classes & pattern matching basics (17+); var keyword (10+)
  • Enhanced switch expressions
  • File I/O with java.nio.file (Files, Path, Paths)
  • Dates & times: java.time — LocalDate, LocalDateTime, ZonedDateTime
Resources
  • PRIMARYJava Brains YouTube — Java 8 Features playlist (concise and clear)
  • BOOKModern Java in Action (Urma et al.) — Chapters 3, 4, 5, 6
  • PRACTICELeetCode — solve 5 Medium problems using Stream API instead of loops
  • ARTICLEBaeldung — Java 8 Streams, Records, Optional (individual articles)
🎯Milestone

Refactor your Week 2 Student system: replace loops with Streams, add an Optional-based search, use Records for the model, and persist data to a JSON file with java.nio.

03

Spring Boot & REST API Development

Weeks 4–6 · The core of backend development

This is the phase most people are excited about — and rightly so. Spring Boot is the dominant Java framework in the industry. But don't rush it. Take three weeks, build incrementally, and understand the why behind every annotation before moving forward.

WEEK 4 Spring Boot Core Concepts
Topics to Cover
  • What Spring Framework is and why Spring Boot exists — the problem it solves
  • Project setup with Spring Initializr (start.spring.io)
  • Maven basics: pom.xml, dependencies, build lifecycle
  • Application structure: Controller, Service, Repository layers — and why
  • Dependency Injection & Inversion of Control — the most important concept
  • @Component, @Service, @Repository, @Controller, @RestController
  • @Autowired and constructor injection (prefer constructor injection)
  • application.properties and application.yml — configuration files
  • Spring Boot DevTools — auto-restart during development
  • Logging with SLF4J and Logback
Resources
  • PRIMARYSpring Official Docs — spring.io/guides (start with 'Building a RESTful Web Service')
  • VIDEOAmigoscode Spring Boot Tutorial (free, YouTube — 3 hour version)
  • BOOKSpring Boot in Action (Craig Walls) — Chapters 1–3
  • PRACTICESpring Initializr — create 3 projects with different dependency sets

@sailikhithk Phase 04 · Databases
04

Databases, SQL & JPA / Hibernate

Weeks 7–8 · Where data lives

Every backend application needs persistent storage. These two weeks cover relational databases, SQL fundamentals, and how Spring Boot talks to a database through JPA and Hibernate. Learn SQL first — don't just rely on JPA to generate queries you don't understand.

WEEK 7 SQL & Relational Databases
Topics to Cover
  • Relational model: tables, rows, columns, primary keys, foreign keys
  • PostgreSQL setup — install locally, create a database, connect with psql
  • DDL: CREATE/ALTER/DROP TABLE, constraints (NOT NULL, UNIQUE, CHECK)
  • DML: INSERT, UPDATE, DELETE, SELECT
  • Filtering: WHERE, AND, OR, IN, BETWEEN, LIKE, IS NULL
  • Sorting & limiting: ORDER BY, LIMIT, OFFSET
  • Aggregations: COUNT, SUM, AVG, MAX, MIN, GROUP BY, HAVING
  • Joins: INNER, LEFT, RIGHT, FULL OUTER — with real examples
  • Subqueries and CTEs (Common Table Expressions)
  • Indexes — what they are, when to create them, performance tradeoffs
  • Transactions: ACID, BEGIN/COMMIT/ROLLBACK, isolation levels
Resources
  • PRIMARYSQLZoo (sqlzoo.net) — interactive exercises, complete all sections
  • PRACTICEpgexercises.com — PostgreSQL exercises with increasing difficulty
  • TOOLDBeaver (free) — visual client for writing and running SQL
  • VIDEOHussein Nasser YouTube — PostgreSQL for Beginners
🎯Milestone

Design a normalized blog schema (users, posts, comments, tags) and write 15 meaningful SQL queries covering all join types and aggregations.

Git, Tooling & Real-World Projects

Weeks 9–10 · Work like a professional

Technical skills alone are not enough. Employers care about how you work, not just what you build. These two weeks focus on professional workflows, tooling, and building a project that demonstrates everything you've learned.

WEEK 9 Git & Professional Workflow
Topics to Cover
  • Git fundamentals: init, add, commit, status, log, diff
  • Branching: branch, checkout, merge, rebase — and when to use each
  • Remotes: clone, push, pull, fetch, remote
  • GitHub workflow: fork, pull requests, code reviews, merge strategies
  • Branching strategies: GitFlow vs trunk-based development
  • .gitignore — what to exclude (target/, .env, *.class, IDE files)
  • Conventional commits — the commit message format used in industry
  • Resolving merge conflicts — don't fear them, practice deliberately
  • GitHub Actions basics — run a test suite on every push (simple CI pipeline)
  • README.md — how to write a project README that actually gets read
Resources

06

Interview Prep & System Design

Weeks 11–12 · Get the job

These final two weeks translate everything you've built into interview readiness. You'll practice DSA problems, review Spring and Java fundamentals, and learn just enough system design to handle entry-level rounds.

WEEK 11 Data Structures, Algorithms & Core Concepts
✍️

Daily schedule: 2 LeetCode problems (Easy/Medium, 45 min each) + 30 min reviewing one Java/Spring concept + 15 min writing it in your own words.

DSA Topics (Java-focused)
  • Arrays & Strings — two pointers, sliding window, prefix sums
  • HashMaps & HashSets — frequency maps, anagram problems
  • Stacks & Queues — balanced parentheses, BFS, monotonic stack
  • Linked Lists — reverse, detect cycle, merge sorted lists
  • Binary Search — on sorted arrays and on answer space
  • Recursion & Backtracking — subsets, permutations, combination sum
  • Basic Trees — traversals (in/pre/post-order), height, LCA
  • Sorting — when to use which (mergesort vs quicksort vs counting sort)
Java & Spring Review
  • JVM internals: heap vs stack, garbage collection, memory model
  • Concurrency basics: threads, synchronized, volatile, ExecutorService
  • HashMap internals — load factor, collision resolution; String pool & immutability
  • Spring Bean lifecycle, scopes (Singleton vs Prototype)
  • @Transactional — propagation types, isolation levels
  • REST design — idempotency, versioning, pagination patterns
Resources
  • DSANeetCode 150 — neetcode.io (curated LeetCode list with solutions)
  • JAVAJavaTpoint Interview Questions; Baeldung — Spring Interview Questions
  • MOCKPramp.com — free peer mock interviews for coding rounds

C

Interview Checklist

Be able to answer every one of these out loud

Java Core

  • Explain the difference between == and .equals()
  • What is the String pool? Why are Strings immutable?
  • Explain HashMap internal working — hashing, buckets, load factor, Java 8 tree bins
  • Checked vs unchecked exceptions — when to use each
  • Abstract class vs interface — when to use which (post Java 8)
  • What is autoboxing? What are its performance implications?
  • Difference between ArrayList and LinkedList
  • Collections.sort() time complexity? What algorithm does it use?

Spring Boot

  • What is Dependency Injection? Why does it help?
  • Explain the Spring Bean lifecycle
  • Difference between @Component, @Service, @Repository — functionally the same?
  • What is @Transactional? What happens if you call it from within the same class?
  • Explain the Spring Security filter chain
  • How does JWT authentication work end to end?
  • Difference between @RestController and @Controller?
  • How do Spring profiles work?
