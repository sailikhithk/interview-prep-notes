4. Why This Is Memorable — Color as Cognitive Anchor

The color system works because each color maps to a cognitive verb, not a section label:

Pink = "STOP, notice this" → pattern signals. Your brain learns to perk up when it sees pink.
Blue = "THINK structurally" → blueprints, frameworks. Analytical mode.
Teal = "GROUND it" → analogies, complexity, evolution. Concrete understanding.
Amber = "WARM UP" → intuition building, dry runs. Get comfortable.
Sky = "EXECUTE" → steps, code. Clear, procedural.
Orange = "WATCH OUT" → edge cases, mistakes. Caution mode.
Purple = "REMEMBER" → flashcards, interview tips. Memory mode.
Indigo = "SCALE UP" → system design, follow-ups. Big picture.

After 5-10 guides, your brain auto-anchors: "I see orange, I'm in caution mode. I see pink, I'm hunting for the pattern." That's the memory hook.
