Overlay is ON, sharingType=.none is ON. Proctor sees a clean screen — the overlay is excluded from CGWindowList.

How it works

NSWindowSharingNone: set window.sharingType = .none. CoreGraphics excludes this window from CGWindowListCreateImage. Zoom/Meet use ScreenCaptureKit which respects this flag. It's a legitimate API — used by DRM apps, banking apps, screen-recording tools. That's why it's hard for Apple to just revoke it.

Detection

Toggle "Proctor uses ScreenCaptureKit force-include" above to see the defender's counter-move. Proctoring platforms can hook SCStreamConfiguration to force-include all windows, ignoring sharingType. The arms race is real.

It's an asymmetric game. Apple controls the OS and can deprecate APIs anytime. Attackers only have public APIs to abuse. Click each quadrant to see who wins and why.

Defender-locked — Hardened Runtime + SIP. Apple's Hardened Runtime + Library Validation (signed-binary-only loading) killed DYLD injection into signed apps in ~2019. SIP prevents kernel-level hiding. Notarization traces binaries to a Developer ID. TCC logs every Accessibility/Screen Recording grant. This is why Tier 3+ evasion is very hard on modern macOS — the defender controls the OS.

2026 reality: defender is winning on macOS

Most "undetectable" interview tools are Tier 1–2 only (cosmetic + persistence blend). They target non-technical proctors at low-tier interviews. FAANG loop proctors run EDR-grade detection and catch them. The economics: cheap tools target cheap interviews.

06What to study next

If you want to go deep on the system design — either to build detection or to understand OS internals — here's the curriculum.

  • *OS Internals* trilogy — Jonathan Levin. Vol I: Userland, Vol II: Kernel, Vol III: Security. The definitive macOS internals reference.
  • Endpoint Security framework — Apple's EndpointSecurity.framework. How EDR works on modern macOS. Read eslogger man page, write a tiny ESF client.
  • TCC / privacy permissions — tccutil, TCC.db schema. Run log show --predicate 'subsystem == "com.apple.TCC"' and watch every permission grant live.
  • ScreenCaptureKit — Apple's modern capture API. Understand SCContentFilter — it's the core of the screen-share-evasion arms race. Build a tiny screen recorder.
  • Code signing + notarization — codesign, spctl, notarytool. Sign a binary, notarize it, then try to DYLD-inject into it.
  • MITRE ATT&CK for macOS — T1564 (Hide Artifact), T1547 (Boot/Logon Autostart), T1055 (Process Injection). Find them on your own machine.
  • Conference talks — DEF CON, Black Hat, OBTS (Objective by the Sea — macOS-specific). Start with OBTS on YouTube.
