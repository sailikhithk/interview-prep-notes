## Pattern Categories

### 1. Creational Patterns
- **Singleton:** Ensuring single instance with thread-safe double-checked locking.
- **Factory Method & Abstract Factory:** Decoupling object creation from business logic.
- **Builder:** Step-by-step construction of complex multi-attribute objects.

### 2. Structural Patterns
- **Adapter:** Bridging incompatible interfaces.
- **Decorator:** Adding responsibilities to objects dynamically without subclassing.
- **Proxy:** Lazy loading, access control, and caching proxies.
- **Facade:** Unified high-level interface over complex sub-systems.

### 3. Behavioral Patterns
- **Strategy:** Swappable algorithmic policies at runtime (e.g., payment methods, sorting strategies).
- **Observer:** Event-driven publish-subscribe pattern across decoupling listeners.
- **Chain of Responsibility:** Passing requests along a handler pipeline (e.g., middleware, auth filters).
- **State Pattern:** Clean finite state machine execution without nested switch-case blocks.
