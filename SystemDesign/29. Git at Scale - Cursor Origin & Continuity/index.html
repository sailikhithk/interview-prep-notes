1 Why is Hosting Git at Scale a Nightmare?

Git was designed by Linus Torvalds for decentralized Linux kernel maintainers. In modern engineering, we demand strong centralization for monorepos (Google, Meta, Uber, Cursor) and millions of automated AI agents committing code concurrently.

Why Distributed Key-Value Stores Fail

Git is content-addressable (keyed by SHA). But accessing files requires traversing a Directed Acyclic Graph (DAG): Commit → Root Tree → Sub-Trees → Blobs.

Latency ≈ ∑ (DAG_Depth × Remote_RTT) ≈ 50 × 2ms = 100ms per file read!
Why Distributed Filesystems (NFS/GFS) Fail

Git stores objects compressed inside binary packfiles using sliding-window delta chains. Object bytes are placed randomly across multi-GB files.

Random seek I/O + network page faults across thousands of repos = unbearable thrashing.

2 Spokes (Gen 2) vs. Continuity (Gen 3) Architecture

GitHub Spokes (2013-2025)

3PC Consensus

Replicates Git repos across local NVMe disks on 3+ nodes. Synchronizes reference transactions using Three-Phase Commit (3PC).

• Tail at scale: Write latency bound by slowest replica ($O(\max \text{latency})$).
• Pets not cattle: Repos are authoritative; loss of 2 disks loses quorum.
• Compaction storms: All replicas repack locally, causing CPU saturation.

Cursor Continuity (2026+)

S3 WAL + Cattle

Source of truth is a Write-Ahead Log in S3. NVMe workers are stateless warm caches routed via Rendezvous Hashing.

• Linear scale: 100+ read replicas fetch directly via fast S3 304 checks.
• Stateless cattle: Any node can rebuild a repo from S3 in seconds.
• Single-leader compaction: Primary repacks; replicas stream pre-compacted packfiles.

1. Write Path (Push)

Packfile streamed to disk & S3. Reference locked locally with libgit2. Atomic S3 CAS executed on index.json. ACK returned to user.

2. Read Path (Fetch/Clone)

Replica validates local cache against S3 using If-None-Match: ETag. Receives sub-10ms HTTP 304 and streams directly from local NVMe.

3. Compaction Path

Primary runs git repack, uploads merged packfile to S3, and commits new manifest. Replicas download merged packs without burning CPU.

4.2 Production Worker & Router Blueprint

import hashlib, json, time
from typing import List, Dict, Optional, Tuple

class RendezvousHashRouter:
    """Highest Random Weight (HRW) Hashing for Zero-DB Routing."""
    def __init__(self, nodes: List[str]):
        self.nodes = sorted(nodes)

    def _hash_weight(self, repo_id: str, node_id: str) -> int:
        key = f"{repo_id}:{node_id}".encode('utf-8')
        return int(hashlib.sha256(key).hexdigest(), 16)

    def get_ranked_nodes(self, repo_id: str) -> List[str]:
        return sorted(self.nodes, key=lambda n: self._hash_weight(repo_id, n), reverse=True)

class ContinuityWorker:
    """Stateless NVMe Worker syncing with S3 Write-Ahead Log."""
    def __init__(self, node_id: str, s3_client):
        self.node_id = node_id
        self.s3 = s3_client
        self.local_cache: Dict[str, dict] = {}
        self.local_etags: Dict[str, str] = {}

    def push(self, repo_id: str, ref: str, old_oid: str, new_oid: str, pack_bytes: bytes) -> bool:
        # 1. Upload immutable packfile concurrently
        pack_sha = hashlib.sha256(pack_bytes).hexdigest()
        self.s3.put_blob(f"repos/{repo_id}/packs/{pack_sha}.pack", pack_bytes)

        # 2. CAS Loop on S3 Index with Exponential Backoff
        for attempt in range(3):
            wal_key = f"repos/{repo_id}/wal/index.json"
            status, wal_data, current_etag = self.s3.get_object(wal_key)
            wal = json.loads(wal_data) if status == 200 else {"epoch": 1, "seq": 0, "refs": {}, "packfiles": []}

            # Fast-forward consistency verification
            if wal["refs"].get(ref) != old_oid and old_oid != "0000000000000000000000000000000000000000":
                raise ValueError("Non-fast-forward push rejected")

            wal["refs"][ref] = new_oid
            wal["packfiles"].append({"sha256": pack_sha, "size": len(pack_bytes), "is_compacted": False})
            wal["seq"] += 1

            # Atomic Compare-And-Swap on S3
            success, new_etag = self.s3.put_object_cas(wal_key, json.dumps(wal), expected_etag=current_etag)
            if success:
                self.local_cache[repo_id] = wal
                self.local_etags[repo_id] = new_etag
                return True
            time.sleep(0.02 * (2 ** attempt))
        return False

1. Rendezvous Hashing (HRW)

$$\text{Node}^*(K) = \arg\max_{i=1}^N h(K \parallel S_i)$$ Eliminates centralized routing databases. Unlike Ketama consistent hashing rings requiring virtual tokens, HRW provides exact top-$k$ ranked lists with $O(1)$ state. 

def get_node(repo_id: str, nodes: list[str]) -> str:
    """Rendezvous Hashing in O(N) time with zero DB."""
